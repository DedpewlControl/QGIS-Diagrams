# French vACC QGIS Diagrams Project

Welcome to the official collaborative repository for the **French vACC QGIS Diagrams Project**.

This repository supports the **creation, collaboration, maintenance, and issue tracking** of the diagrams used by the French vACC. It contains the QGIS project files, layers, styles, labels, and configuration required to keep each diagram consistent, accurate, and easy to maintain.

---

> ⚠️ **Important**
>
> This repository contains the **source files used to create the diagrams**. It may not contain every exported, ready-to-use diagram.
>
> Published diagrams are generated from these sources and distributed through the appropriate French vACC platforms and documentation.

---

## 🐞 Bug Reporting

Have you found an issue with a diagram?

- Outdated information
- Incorrect or missing labels
- Invalid colours or styling
- Geometry or positioning errors
- Missing operational information
- General improvements or suggestions

👉 Please open an issue and include the name of the affected diagram, a clear description of the problem, and screenshots when possible.

Clear and detailed reports help us investigate and correct issues more quickly.
